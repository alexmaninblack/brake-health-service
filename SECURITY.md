# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately through this GitHub repository's security
advisory interface. Do not disclose an unpatched vulnerability, credential,
vehicle identity, private endpoint, certificate, or exploit in a public issue.

Include the affected revision, impact, reproduction conditions, and any known
mitigation. Remove all real credentials and personal or customer data from the
report.

## Supported Versions

No production release exists during repository bootstrap. A supported-version
table will be published with the first tagged service release.

## Credential Incidents

If sensitive material is committed, revoke or rotate it before relying on Git
history cleanup. Repository history rewriting does not invalidate an exposed
secret.
